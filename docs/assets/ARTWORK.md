# Documentation artwork

Generated with the built-in imagegen tool for the portfolio documentation. The banner and canonical/index image use a minimal black, ivory, and orange graphic style. They are conceptual illustrations, not product screenshots. The dashboard PNGs are product captures; `session-handoff.gif` is rendered from actual scripted MCP output.

The README uses the banner. The engineering notes use the canonical/index illustration alongside the technical architecture described in the README. Images link to repository-hosted assets so the npm README does not depend on excluded package artwork.

## README banner

File: `horizonlayer-banner.png`

Prompt:

> Use case: ads-marketing. Asset type: wide 3:1 GitHub README banner for HorizonLayer, a developer tool for persistent project knowledge and shared work. Generate a completely fresh, cool and radically minimal graphic identity. Flat editorial graphic, inspired by Swiss modernist posters and precise technical printmaking. Background near-black ink, foreground warm white, one tiny burnt-orange accent. Extremely clean oversized negative space, no textures, no gradients. On the left: exact text 'HorizonLayer' in beautifully kerned bold grotesk sans serif; beneath small understated exact text 'Persistent knowledge. Shared work.' On the right: a single striking abstract horizon symbol made of five thin ivory parallel horizontal lines that step up into one compact offset stack, a small orange square tucked on the horizon. Geometry is precise, spare, confident, sophisticated. Wide panoramic framing with generous margins. Crisp flat raster artwork, typography must be perfectly readable. No 3D, no stone, glass or marble, no glowing networks, no landscapes, no fake UI, no robots, no decorative circuitry, no extra text or watermark.
