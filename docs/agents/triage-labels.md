# Triage tags

The engineering skills use these role names as HorizonLayer Issue tags rather than GitHub labels:

| Role | HorizonLayer tag | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | The maintainer still needs to evaluate the Issue |
| Needs information | `needs-info` | Work is waiting for a specific answer |
| Ready for agent | `ready-for-agent` | The Issue has a complete implementation brief |
| Ready for human | `ready-for-human` | The Issue still needs human judgment or manual work |
| Won't fix | `wontfix` | The Issue will not be actioned |

Category tags such as `bug` and `enhancement` are separate from state tags. Wayfinder planning tags are also separate: a `wayfinder:<type>` tag marks an unresolved decision ticket, not an implementation ticket.
