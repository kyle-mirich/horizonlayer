# Domain docs

This is a single-context repository.

Before changing the domain model, read [the project glossary](../glossary.md) and the relevant [engineering notes](../engineering-notes.md). The glossary is the current source for names such as Knowledge Workspace, Issue Project, Canonical Knowledge, Derived Search Index, Backup, and Runtime Recovery.

If a new domain term needs to be resolved, create or update `CONTEXT.md` at the repository root using the domain-modeling skill. Create `docs/adr/` lazily for decisions that are hard to reverse, surprising without context, and the result of a real trade-off. Do not use `CONTEXT.md` as a specification or implementation checklist.
